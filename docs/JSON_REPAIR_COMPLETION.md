## 🎯 实施内容

### 1. 核心功能实现

**新增函数**：`_repair_json(text: str) -> str`

**位置**：`app/api/toolcall.py`

**功能**：自动修复常见的 JSON 格式错误

**支持的修复策略**：
1. ✅ 单引号转双引号（`'key'` → `"key"`）
2. ✅ 移除尾部逗号（`{"a": 1,}` → `{"a": 1}`）
3. ✅ 组合修复（同时处理多种错误）
4. ✅ 多次尝试修复（4 种策略）

### 2. 集成到现有代码

**修改函数**：`_decode_param_value(raw: str) -> Any`

**集成位置**：
- CDATA 内容解析失败时
- 普通 JSON 解析失败时

**工作流程**：
```
尝试解析 JSON
    ↓
  失败？
    ↓
调用 _repair_json() 修复
    ↓
  成功？
    ↓
返回解析结果
```

## 🔍 实际效果示例

### 修复前（失败）
```python
# 模型输出
parameter = "<![CDATA[{'city': 'Beijing', 'days': 3,}]]>"

# 解析失败
try:
    json.loads("{'city': 'Beijing', 'days': 3,}")
except JSONDecodeError:
    # ❌ 解析失败，返回字符串
    return "{'city': 'Beijing', 'days': 3,}"
```

### 修复后（成功）
```python
# 模型输出
parameter = "<![CDATA[{'city': 'Beijing', 'days': 3,}]]>"

# 自动修复
repaired = _repair_json("{'city': 'Beijing', 'days': 3,}")
# → '{"city": "Beijing", "days": 3}'

# 解析成功
result = json.loads(repaired)
# ✅ {'city': 'Beijing', 'days': 3}
```

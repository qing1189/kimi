## 🎯 两个项目的核心区别

| 维度 | 当前项目 (ds2api 风格) | 参考项目 (简化风格) |
|------|----------------------|-------------------|
| **格式复杂度** | 高（类 XML） | 低（简洁） |
| **标记示例** | `<\|DSML\|tool_calls>` | `[function_calls]` |
| **参数包裹** | CDATA 必需 | 直接 JSON |
| **Prompt 长度** | ~200 行 | ~40 行 |
| **模型遵守难度** | 较难 | 较易 |
| **防泄露机制** | ✅ 完善 | ⚠️ 基础 |
| **XML 修复** | ✅ 支持 | ❌ 不支持 |
| **JSON 修复** | ❌ 缺失 | ✅ 支持 |
| **白名单验证** | ❌ 缺失 | ✅ 支持 |
